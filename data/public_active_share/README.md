# Public Active Share inputs

Place the original Notre Dame Active Share public datasets in this directory for local dashboard inspection:

- Historical TR dataset (coverage through 2019)
- CRSP extension (2020–September 2023)

Accepted file types: CSV and Parquet. Files are not automatically pooled. The dashboard keeps source files separate until the provider bridge has been validated.

## Important
Do not commit licensed, restricted, or user-specific data. The dashboard currently performs only file loading and audit/preview. No published baseline statistics are generated until the raw data is available and reproducibly processed.
